03 / THE ESSENTIALS

Everything you need.
Nothing in the way.

A simple viewing experience, designed around the model instead of the software.

Right-click to open

Register GLB Viewer once, then right-click any GLB file and choose Open With > GLB Viewer.

Desktop works offline

The desktop viewer uses local Three.js assets. The browser demo loads its viewer engine and sample model from the web.

Your files never leave your PC

No upload, no tracking of models, no cloud. We track downloads only, never your files.

Lightweight

Vanilla HTML/CSS/JS. No React, no build step, no framework. Just open viewer.html and go.

Quick, straightforward answers about viewing your 3D files, privacy and what GLB Viewer can do.

Still have a question? Ask on GitHub ↗
01How do I open a GLB file online?

Open the GLB Viewer live demo, then drag a .glb file into the preview or choose it from your device. Your browser reads and renders the selected file locally in the current tab.

02Is GLB Viewer free?

Yes. GLB Viewer is free and open source under the MIT License. Use the browser preview or download the Windows desktop workflow without a subscription.

03Does it upload my 3D files?

No. Files selected for the browser demo are loaded locally by your browser and are not sent to GLB Viewer servers. The website does download its viewer code and the optional sample model.

04Can I view GLB files on Windows?

Yes. Use the online browser viewer, or install the Windows desktop workflow to open local GLB files through Windows Open With.

05Can I open glTF files too?

The browser demo accepts .glb and .gltf files. A glTF file that references external textures or binary assets may need those companion files to be available through the same folder or a supported local loading workflow.

06Is this a replacement for Blender?

No. GLB Viewer is designed for quick viewing and inspection, including rotate, zoom and pan. It is not a 3D modelling, sculpting, animation-authoring or material-editing replacement for Blender.

07Which browsers support the 3D viewer?

Use a recent Chrome or Edge browser with WebGL enabled. Performance depends on your graphics hardware, browser and the complexity of the 3D model.
