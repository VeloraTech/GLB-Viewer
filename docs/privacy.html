Privacy

Your files never leave your computer. We never upload.

1. Your models stay on your computer

GLB Viewer is a local, offline application. When you open a GLB file, it is loaded entirely in your browser on your machine. Nothing is uploaded to any server. No model data, no file names, no file sizes, and no thumbnails ever leave your computer.

2. What we track (and what we don't)

We use a privacy-friendly analytics placeholder (Plausible or Umami) on the website landing page only. It tracks:

  • Operating system (for download button relevance)
  • Download button clicked (which OS you chose)
  • Demo viewer used (whether you opened the in-browser demo)

We do not track file names, file sizes, models, or any personal data. We track downloads, not your models.

3. File association permission

Registering GLB Viewer as the "Open With" handler for .glb files requires write access to the Windows registry. We need this access so you can right-click a file and open it with GLB Viewer. Your files never leave your computer. We never upload.

4. No accounts, no personal data

GLB Viewer does not require an account. We do not collect email addresses, names, or any personally identifiable information.

5. Questions

If you have questions about this privacy notice, open an issue on GitHub.
