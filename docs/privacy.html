GLB VIEWER / PRIVACY

Your models are yours.
Your files stay local.

GLB Viewer is built to open and inspect 3D files without asking you to send those files to us. This page explains what happens on your device, what the website loads, and where the boundaries are.

Plain-language privacy noticeLast updated: 10 November 2026
01

Your model is not our data.

Opening a model in the desktop viewer or choosing a file in the browser demo does not upload that model to GLB Viewer. Rendering and inspection happen locally in your browser or on your computer.

01 / YOUR FILES

What happens when you open a 3D model?

The desktop viewer is designed to work locally. When you open a .glb file through the Windows Open With workflow, the launcher serves the viewer on your own machine and the model is read by that local viewer. The model is not sent to a GLB Viewer server as part of that workflow.

The browser demo follows the same local-file principle. When you select or drop a .glb or .gltf file, the page creates a temporary browser object URL and passes it to the 3D loader. The model is rendered in the current browser tab; the page does not contain an upload endpoint for your model.

  • We do not ask you to create an account to view a model.
  • The demo does not transmit the model file, its contents, or a thumbnail to our application backend.
  • The browser object URL is temporary and is revoked after loading or when an error occurs.
  • Closing the tab ends that page session; the demo does not provide cloud model storage.

Important distinction: local rendering does not mean the entire website is offline. The landing page and browser demo load web resources, described below. The standalone desktop viewer is the offline-oriented part of the product.

02 / WEBSITE AND DEMO

The website still makes web requests.

To display the landing page and its interactive preview, your browser requests the website files and the Three.js rendering modules from the jsDelivr content delivery network. The hero preview is generated locally in the page. These requests are for website code and interface resources, not for uploading your selected model.

Your browser and the services that deliver the website may process standard connection information, such as an IP address, browser details, requested resource and request time, as part of serving web content. Those services operate under their own policies and infrastructure.

If you choose a file for the in-browser demo, the file is read by the page in your browser. It is not included in the normal website resource requests.

03 / ANALYTICS

What the current site measures.

The landing page currently includes the Plausible Analytics script, configured with the site domain glb-viewer.pages.dev. The site also contains a small event-tracking placeholder that currently writes event labels to the browser console; it does not send those custom events to an analytics endpoint.

Because the configured Plausible domain may not match the address from which you are visiting the site, analytics may not record visits to every deployment. We do not use the current custom event placeholder to collect model names, model contents, file sizes, thumbnails or file paths.

For details about how Plausible handles analytics data, read Plausible's data policy. The provider's policy applies to its own processing.

04 / PERMISSIONS

What installation changes on your computer.

On Windows, registering GLB Viewer as an Open With option requires adding a file association to the Windows Registry. This allows Windows to offer GLB Viewer when you right-click a .glb file. The registry change is local to your computer and is not a permission to access or upload your model library.

The viewer needs access to the file you explicitly open so it can display it. It does not need an account, an online storage account, or a server-side copy of your model.

05 / EXTERNAL SERVICES

Services outside the viewer.

The website links to GitHub for source code, releases, issues and community discussions. The landing page also loads Three.js modules from jsDelivr and includes the Plausible script described above. When your browser contacts these providers, their own privacy terms and technical logs apply.

GLB Viewer does not control the independent data practices of GitHub, jsDelivr, Plausible, your browser, your operating system or your network provider. Review their policies if you want details about their processing.

06 / STORAGE AND RETENTION

No GLB Viewer cloud library.

The product does not currently provide user accounts, cloud sync, remote model storage or a server-side model history. The browser demo keeps the selected file available to the current page session for rendering; it does not create a persistent cloud copy.

Any local copies or files you choose to keep remain under your control. Browser cache, downloaded release files and operating-system records are managed by your browser or operating system, not by a GLB Viewer account.

07 / YOUR CHOICES

You decide what to open.

  • You can use the standalone viewer without visiting the website after you have the required files on your computer.
  • You can avoid the browser demo and use the desktop viewer instead.
  • You can choose not to load the landing page if you do not want its third-party website resources requested.
  • You can inspect the source code and raise a concern through the public repository.

Do not open a file on a device or in a browser you do not trust. Keep your operating system and browser up to date, as you would with any software that reads local files.

08 / QUESTIONS AND UPDATES

Privacy should be inspectable.

If something in this notice is unclear, or you believe the application behaves differently from what is described, please open a GitHub issue. Include the page or feature involved, but do not attach private model files or other sensitive material.

This notice may change as the product and its website services change. The revision date above identifies the latest version published with this site. Material changes should be reflected here rather than hidden in a generic promise.
